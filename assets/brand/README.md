# Brand assets

`epsilon-logo.png` is the welcome-screen logo based on the owner-supplied
EPSILONLogo.pdf (2026-11-01), with the white page and border removed using
ImageGen. It preserves the blue epsilon/arrow artwork on transparent pixels.
The native app icons remain placeholders; theme blue remains provisional.

The three `app-icon*.png` files are static epsilon-text placeholders generated by
`scripts/generate-placeholder-assets.ps1`. They repair missing configured native
assets: transparent foreground, white flat icon, black monochrome mask. They are
not an approved production logo.

`splash-blank.png` is a transparent 1024px image: the native splash is plain white
and hands over to the in-app launch intro (`src/components/brand/BrandIntro.tsx`).

`loading/` holds the launch-intro assets, generated from the official logo by
`assets/animations/epsilon-logo/render_epsilon_draw.py app` (do not edit by hand):
the one-stroke draw video of the mark (720×588, 60 fps, ends on the finished mark),
the finished mark as a transparent PNG framed exactly like the video, and the seven
wordmark letters. The same run regenerates `src/components/brand/brandIntroAssets.ts`.

`google-g.svg` wraps the unmodified Google-provided PNG in an SVG image so the
current gradient G renders consistently through react-native-svg, without
unsupported SVG conic gradients/foreignObject. `google-g.ts` is the same SVG
serialized for Metro (no SVG transformer dependency). No network image request.

Source: https://developers.google.com/static/identity/images/g-logo.png
Usage: https://developers.google.com/identity/branding-guidelines
Google brand assets remain Google's trademarks and are used only in its sign-in
button under those guidelines. They are not Epsilon branding or licensed as
Epsilon source code. Native Google authentication is feature-gated and uses the
original Google sign-in SDK; its ID token is exchanged only with the backend.
